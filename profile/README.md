| [yougedazi-app](https://github.com/CosmGrid/yougedazi-app) | 移动端 App |
| [yougedazi-admin](https://github.com/CosmGrid/yougedazi-admin) | 管理后台 |
| [yougedazi-partner](https://github.com/CosmGrid/yougedazi-partner) | 商户端 |
| [yougedazi-web](https://github.com/CosmGrid/yougedazi-web) | Web 端 |
